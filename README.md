# torgovlya — Bitcoin Lab

Статический сайт для проверки десяти гипотез на Binance BTCUSDT Spot.

В `btc.bin` лежат настоящие OHLCV 15m за 2020-01-01 — 2026-09-30: little-endian Float64, по 7 чисел на строку (open timestamp в миллисекундах UTC, open, high, low, close, volume, quote volume). Источники и официальные SHA256 архивов находятся в `data-manifest.json`. 2020 год служит прогревом.

Расчёт выполняется в браузере в отдельном Web Worker. `engine.js` также запускается в Node.js. Нет подключения к аккаунту биржи и исполнения реальных ордеров.

Локальный запуск: `python -m http.server 8765 --bind 127.0.0.1 --directory .`, затем открыть `http://127.0.0.1:8765/`. Прямое открытие index.html через file:// не поддерживает Worker и загрузку данных.

Проверка движка: `node audit-engine.cjs`. Проверка сравнивает исходные настройки всех десяти гипотез с сохранёнными результатами независимого Python-бэктеста по числу сделок, доходности, максимальной просадке и среднему R с погрешностью 1e-7.

Таймфрейм сигналов и таймфрейм графика независимы. При изменении таймфрейма сигналов N свечей относится к новому таймфрейму; дневные уровни, диапазон 00–06 UTC и фильтр 30 завершённых дней остаются привязанными к UTC дням. Это создаёт новый вариант гипотезы. Для стратегии 7 крупные таймфреймы могут не формировать допустимых внутридневных сигналов. Для стратегии 10 изменение исходного 1D переносит её EMA и структуру отката на выбранный таймфрейм.

Комиссия и проскальзывание фиксированы на каждую сторону. Размер позиции ограничен наличными, риск рассчитан по полному ожидаемому убытку. Цели обеспечивают чистое RR: минимум 3,5 для гипотезы 3 и 4 для гипотезы 10. При двойном касании в одной 15m свече стоп считается первым; при открытии выше цели — выход по цели. В конце выбранного периода открытая позиция принудительно закрывается, поэтому её фактический R может быть меньше целевого.

Пустые интервалы в агрегированных свечах имеют NaN OHLC, нулевой объём и не создают новые сигналы; искусственные цены не добавляются. Гэпы, реальные очереди ордеров, фильтры lot-size и спред не воспроизводятся полностью.

WebMCP инструменты, если поддерживаются браузером: configure_bitcoin_backtest, run_bitcoin_backtest, read_bitcoin_backtest_result. Работают через те же настройки и действия, что и интерфейс.
